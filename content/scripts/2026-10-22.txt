Good morning. Today's through-line is the bill for AI. Some of it's in dollars. Some of it's in risk. Three stories.

First, the risk one. Because yesterday, the people who maintain PHP shipped patches for two critical bugs.

Now, PHP. If you don't write code, here's all you need. It's the language behind a huge slice of the web. WordPress runs on it. A lot of the sites you visit every day run on it. And the two flaws would let a stranger run their own code on a server, without logging in.

The project rates both of them a nine point two out of ten for severity. That's near the top.

How does it work? Roughly this. One bug is about PHP running out of memory at exactly the wrong moment. It leaves half-built data lying around, and later PHP trusts it. The other leaves stale memory behind after a crash, and the next request can reuse it. Dull-sounding stuff. Dangerous stuff.

The worst exposure, the project says, is servers running a module called mod_php. There, a stranger's request can trigger the attack before the site's own code even starts.

Here's the part that belongs in this newsletter. The security firm Wiz found these. And Wiz says it used three AI systems to do it. Its own agent, called Wiz Atlas. Google's Gemini 4 Argon. And OpenAI's GPT-5.6 Sol. Wiz says it found the first bug in mid-August, and had working attacks against Drupal and WordPress within days.
